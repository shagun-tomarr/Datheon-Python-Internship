Hangman Word Guessing Game

Datheon Python Programming Internship — Task 1

Project Overview

This project is a console-based Hangman Word Guessing Game developed using Python 3. The player attempts to guess a randomly selected hidden word one letter at a time.

Features

- Random word selection using Python's random module.
- Interactive letter-by-letter guessing.
- Maximum of six incorrect guesses.
- ASCII Hangman graphics that update after incorrect guesses.
- Tracks previously guessed letters.
- Prevents duplicate guesses from deducting extra attempts.
- Displays victory and defeat messages.

Technologies Used

- Python 3
- random module
- Standard Python libraries

How to Run

1. Download the "hangman.py" file.
2. Open it in a Python 3 environment that supports interactive input.
3. Run the program.
4. Enter one letter at a time when prompted.

Learning Outcomes

This project demonstrates the use of variables, strings, sets, loops, conditional statements, functions, user input, and random selection in Python.
